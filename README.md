# depviz — визуализатор зависимостей

Практическая работа, вариант № 3. Программа на Python получает и отображает зависимости пакетов.

## Этап 1. Конфигурация

Пользовательские настройки хранятся в `config.ini`: имя пакета, адрес Maven-репозитория, режим тестового репозитория и строка фильтрации. На этом этапе приложение проверяет параметры и выводит их в формате «ключ = значение».

Запуск: `python -m depviz`. Ошибки конфигурации выводятся с пояснением.

## Этап 2. Сбор прямых зависимостей

Программа строит адрес POM Maven по координатам пакета, загружает XML и выводит его прямые зависимости. Для тестового режима можно использовать JSON-репозиторий; для реальной загрузки используйте `examples/config-maven.ini` и запустите `python -m depviz --config examples/config-maven.ini`.

## Этап 3. Транзитивный граф

`depviz/graph.py` строит граф итеративным BFS, применяет фильтр и не зацикливается на повторных узлах. Примеры A, C и F находятся в `examples/`; в учебном JSON есть цикл `B → D → G → B`.
