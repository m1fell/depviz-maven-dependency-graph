# depviz — API визуализации зависимостей

Практическая работа, вариант № 3. Приложение на Python собирает зависимости Maven, строит граф обходом в ширину и предоставляет данные и файлы диаграммы через HTTP API. Пользовательского HTML/CSS/JavaScript-интерфейса нет.

Для работы приложения нужны Python 3.10 или новее и только его стандартная библиотека. Maven и сторонние библиотеки не используются для получения зависимостей. Для тестового графа интернет не нужен.

## Запуск

Откройте проект в PyCharm и запустите конфигурацию **depviz — API** либо выполните в терминале:

```bash
./run.sh
```

В тестовом режиме приложение покажет в терминале список пакетов из тестового репозитория. Введите номер или имя пакета. После этого программа напечатает параметры и зависимости, сохранит SVG и PlantUML в `output_dir`, запустит API и откроет в браузере ссылку, по которой сразу скачивается SVG выбранного графа. Сервер останется работать, пока не нажать `Ctrl+C`.

Клавиша Enter выбирает пакет, указанный в `config.ini`. Чтобы сразу выбрать пакет без меню, передайте `--package C`; чтобы сервер не запускал браузер автоматически — добавьте `--no-browser`.

Для другого файла настроек, адреса или порта:

```bash
./run.sh --config examples/config-c.ini --host 127.0.0.1 --port 8080
```

В тестовом режиме меню и API принимают имя пакета из JSON-графа, например `A`, `B` или `C`. В Maven-режиме используется пакет из конфигурации; `--package` позволяет указать другие координаты `groupId:artifactId:version`.

## Маршруты API

| Запрос | Результат |
| --- | --- |
| `GET /api/health` | Проверка, что сервер запущен |
| `GET /api/graph?package=A` | JSON: прямые зависимости, узлы, рёбра и глубины BFS |
| `GET /api/graph?package=A&reverse=G` | Тот же JSON и список обратных зависимостей для G |
| `GET /api/graph.svg?package=A` | Показать SVG-граф прямо в браузере |
| `GET /api/graph.svg?package=A&download=true` | Скачать SVG отдельным файлом |
| `GET /api/graph.puml?package=A` | Скачивание отдельного файла диаграммы PlantUML |

При обычном запуске браузер сам откроет граф выбранного пакета. Чтобы вручную показать другой граф, откройте, например, `http://127.0.0.1:8000/api/graph.svg?package=C`. Чтобы скачать его отдельным файлом, используйте:

```bash
curl -OJ "http://127.0.0.1:8000/api/graph.svg?package=A&download=true"
```

Файлы SVG и PlantUML также сохраняются в `output_dir` при старте программы. SVG можно открыть в браузере, масштабировать или вставить в отчёт.

## Тестовый репозиторий и примеры

`examples/test_repository.json` задаёт список прямых связей. В графе намеренно есть цикл `B → D → G → B`; BFS отмечает уже посещённые узлы и не зацикливается. Примеры конфигурации задают разные корневые пакеты:

```bash
./run.sh --config examples/config-a.ini
./run.sh --config examples/config-c.ini
./run.sh --config examples/config-f.ini
```

Для ручной демонстрации фильтра укажите `filter_substring = E` в копии конфигурации. Пакет E и его связи будут исключены. Обратные зависимости можно вывести в консоль при старте, например `./run.sh --config examples/config-a.ini --reverse G`; в API для этого предназначен параметр `reverse`.

Для получения данных из Maven Central используйте `examples/config-maven.ini` или переключите `test_mode = false` и укажите координаты Maven-пакета в `config.ini`. Требуется доступ к интернету.

## Этапы практической работы

1. **Конфигурация:** `src/depviz/config.py` загружает INI-настройки и проверяет ошибки.
2. **Сбор данных:** `src/depviz/repository.py` загружает POM по URL и читает прямые зависимости.
3. **Граф:** `src/depviz/graph.py` строит транзитивные связи итеративным BFS, применяет фильтр и корректно обходит циклы.
4. **Обратные зависимости:** поиск использует BFS по обратным рёбрам графа.
5. **Визуализация:** `src/depviz/render.py` формирует PlantUML и SVG; API отдаёт их отдельными файлами для скачивания. Примеры A, C и F находятся в `examples/rendered/`.

Для сравнения был использован Maven 3.9.11 и команда `mvn dependency:tree` на контрольном проекте. Для `commons-text:1.12.0` обе реализации показали зависимость `commons-lang3:3.14.0`. Maven применялся только для контрольного сравнения, приложение не использует его для получения зависимостей.

## Ограничения парсера Maven

Парсер раскрывает Maven properties, наследует зависимости и `dependencyManagement` из parent POM, а также читает версии из импортированных BOM. В граф попадают зависимости scope `compile` и `runtime`. Полная логика Maven всё ещё не воспроизводится: активные профили, исключения зависимостей, диапазоны версий и выбор одной версии при конфликте не обрабатываются. Поэтому на сложных проектах результат может отличаться от `mvn dependency:tree`.

## Термины

- **Зависимость** — пакет, который нужен другому пакету.
- **Прямая зависимость** — указана непосредственно в POM выбранного пакета.
- **Транзитивная зависимость** — нужна одной из зависимостей.
- **Граф** — узлы-пакеты и рёбра-связи между ними.
- **BFS (поиск в ширину)** — алгоритм, который сначала обходит ближайшие узлы, затем следующие уровни.
- **POM** — XML-файл Maven с описанием пакета и зависимостей.
- **API** — адреса HTTP-сервера, через которые другая программа или браузер получает данные и файлы.
- **SVG** — векторный формат изображения, поддерживаемый браузерами.
- **PlantUML** — текстовый формат описания диаграмм.
